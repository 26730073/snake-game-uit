⚠️ 3 QUY TẮC BẮT BUỘC KHI CODE

1. KHÔNG code trực tiếp trên nhánh main
Mỗi lần làm việc gì thì tạo nhánh mới:

git pull origin main
git checkout -b feat/ten-viec-minh-lam

Code xong thì:
git add .
git commit -m "feat: mô tả ngắn việc vừa làm"
git push -u origin feat/ten-viec-minh-lam

Rồi lên GitHub bấm nút vàng "Compare & pull request", nhắn nhóm nhờ người khác duyệt.

2. Trước khi code luôn chạy "git pull origin main" để lấy code mới nhất

3. Chỉ sửa file của mình. Cần sửa file người khác thì nhắn cho người đó trước.

📖 Hướng dẫn Git đầy đủ cho người mới, có cả cách xử lý lỗi hay gặp:
https://github.com/tronghv77/snake-game-uit/blob/main/docs/HUONG-DAN-GIT.md
